# Task-03 Submission Summary

**Task:** Implement an SVM to classify cats and dogs from the Kaggle Dogs vs Cats dataset.

**Dataset:** Kaggle Dogs vs Cats competition.

**Algorithm:** Support Vector Machine with RBF kernel.

**Image preprocessing:** Resize to 64×64 grayscale.

**Feature extraction:** Histogram of Oriented Gradients (HOG).

**Evaluation:** Accuracy, precision, recall, F1-score and confusion matrix.

**Prediction:** CLI script + Flask upload application.
